# docs

Everything here is committed and safe to publish. Nothing in it describes a specific project: project names, paths, ports and notes live in the private, gitignored `../registry/` folder, whose template is `../registry.example/` ([ADR 0007](decisions/0007-keep-project-information-out-of-the-repo.md)).

- `guides/claude-cli.md`: how to work with Claude from the terminal; the viewer shows it in its Claude CLI panel
- `guides/use-cases.md`: everyday jobs, step by step across the viewer, Archeion's session and a project's session; the viewer's Use cases page
- `roadmap/roadmap.md`: now / next / later for Archeion itself, plus dated plans for larger initiatives
- `decisions/NNNN-title.md`: architecture decision records (context, decision, consequences)
- `notes/`: session handoff notes, written by `/workspace-core:handoff`
