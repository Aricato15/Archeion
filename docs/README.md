# docs

- `system/overview.md`: the big picture of all projects
- `system/projects/<project>.md`: the project registry, one page per project or sub-project (frontmatter facts plus cross-project notes; see `system/projects/README.md`)
- `system/groups/<group>.md`: one page per system of related projects
- `interactions/`: notable cross-project flows (the maps are generated from the registry)
- `roadmap/roadmap.md`: now / next / later, plus dated plans for larger initiatives
- `decisions/NNNN-title.md`: cross-project architecture decision records (context, decision, consequences)
- `notes/`: session handoff notes, written by `/workspace-core:handoff`
