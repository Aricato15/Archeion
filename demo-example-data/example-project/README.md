# Example-Project

A made-up online bookshop. It exists only to show what Archeion's views look like for a real project: the docs, the design and its checklist, the roadmap, and the glossary.

- Browse and search the catalogue, fill a cart, check out with a hosted payment page, and get an email receipt.
- One service, one SQLite database file.

See [ROADMAP.md](ROADMAP.md) for what's done and what's next, and [docs/](docs/) for the notes.
